# 图像角色

## `documentary`

必须有真实来源文件。允许去尘、划痕修复、温和降噪、色彩 / 明暗恢复、裁切、旋转和尺寸调整；不得替换人物、改变身份特征、合成不存在的场景或生成“像真的”历史照片。修复记录要写明操作和源文件。

## `design`

用于纹理、背景、抽象隐喻和装饰图。默认生成无可读文字版本，为排版层预留安全区。不得复制单一案例的完整构图和独特元素组合。

## `memory-illustration`

用于没有照片的回忆片段。可以写实、绘画、拼贴或其他艺术化表达，但图注或素材记录必须明确 `非纪实照片`。不得虚构原文没有的人物身份、地点或关键事实；未知外观使用非识别性表达或进入待确认。
