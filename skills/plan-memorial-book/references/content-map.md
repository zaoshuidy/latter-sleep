# 内容地图方法

对每个发现记录来源内容单元 ID；不确定值使用 `status: 待确认`，不要用常识填空。

| 维度 | 记录内容 |
|---|---|
| 人物 | 姓名或原文称呼、关系、相关单元 |
| 时间 | 原文时间表达、精度、相关单元 |
| 地点 | 原文地名或场景称呼、相关单元 |
| 事件 | 发生了什么、参与者、相关单元 |
| 主题 | 反复出现的意义线索及证据单元 |
| 图片关联 | 图片 ID、可对应的文字单元、关联依据 |
| 缺口 | 缺失字段、影响、确认状态 |

内容地图用于检索与比较结构，不得成为重写正文的中间稿。

## 结构候选

候选可使用 `time`、`theme`、`place`、`relationship`、`event`、`object`、`photo` 或 `hybrid`。选择依据来自材料密度与项目目的，而不是预设“回忆录必须按年代”。每套记录 `unit_order`；在人工确认前不实际移动源文件。
