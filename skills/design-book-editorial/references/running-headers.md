# 页眉页脚

优先复用 `templates/running-headers/` 的结构。项目只替换字体、颜色、书名、章节名和已允许的位置变量。

- 左右页来源必须明确；长标题按模板回退为短标题字段、截断加完整目录关联或隐藏页眉，不能改章节正文。
- 章首页、空白页和全出血图片页统一隐藏导航。
- 页眉页脚不得侵入正文有效版心；位置与印刷边界在后续排版软件中复核。
- 版权页已从 V1 页面类型中排除，不在隐藏清单或生产规则中创建。

## 文学小说默认导航

- 普通 145 × 210 mm 文学小说默认复用 `folio-outer`：不设置书名或章名页眉，只保留外侧底部页码，基线距离成品页底 `12 mm`。
- 页码必须随左右页镜像并位于翻口侧，不得放在装订侧；章首页、空白页和全出血图片页隐藏显示但保持计数连续。
- 只有章节检索需求明确、书名／章名长度经过样页验证时，才改用 `paired-standard`；装饰性页眉不作为默认项。
- 上述数值是本套件对普通文学小说的稳定起点；正式印刷前仍需结合裁切与装订复核。
