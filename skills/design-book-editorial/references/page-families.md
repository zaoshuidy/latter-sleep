# 页面家族

每本书选择 5～8 个核心页面家族，数量按真实内容决定。常用候选包括封面接口、目录、章首页、纯文字正文、图文正文、全图或组图、书信 / 日记原件、年表 / 附录；版权页不在 V1。

每个家族记录用途、网格、可变字段、溢出策略、可编辑文字层和图片槽。页面家族是同一本书的系统，不是跨项目无差别套版。
