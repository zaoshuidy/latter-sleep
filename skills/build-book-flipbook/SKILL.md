# 搭建可翻阅电子样书

## 核心原则

这是成书后的展示阶段，不是重新设计阶段。沿用已批准的封面、目录、章首页、正文、页眉页脚和真实文字；不得重新设计已批准页面。

翻页内核固定使用本地化的 `page-flip@2.0.7`（StPageFlip，MIT）。不得手写翻页状态机，也不得用切换整张跨页的淡入淡出冒充翻页。

根据已经批准的页面形态只选一种实现模式：

- **视觉还原与流畅度优先**：页面已是批准 PNG/JPEG，读取 `references/approved-png-canvas-mode.md`，使用原生 Canvas 图片模式。这是成品展示默认方案。
- **文字可选与硬封壳优先**：页面仍以真实 HTML 文字排版，读取 `references/stpageflip.md`，使用 HTML 页面模式。

不要把两种模式叠在同一物理页上，也不要为了可搜索文字在动画页上覆盖透明 DOM 文本层。

## 输入门槛

- 页面顺序、奇偶页和空白补位已经确定。
- 文字来自项目真实稿件，图片来自项目已批准资产。
- 页面尚未批准时，返回 `design-book-editorial`，不要在展示阶段补设计决策。

## 直接交付

1. 判断输入是批准图片页还是 HTML 文字页，并读取对应参考文件。
2. 严格保持物理单页顺序、奇偶页、空白补位和首尾封面，不改动批准页面内容。
3. 只增加薄适配层：上/下一页、目录跳转、键盘、页码、全屏和移动端单页适配。翻页计算全部交给 StPageFlip。
4. 输出一个主 HTML、项目内本地引擎包及许可证。不得依赖 CDN、后端、数据库或 iframe 页面集合。
5. 新版本另存，保留上一版作为可直接回退的成品，不覆盖已通过验收的版本。
6. 断网验证正封、跨页、目录跳转、末页封底、窄屏、清晰度、失败回退和浏览器控制台；HTML 模式另验正文选取。

## 完成标准

- 双击或静态文件服务均可阅读，Network 无外网请求。
- `showCover: true`；正文页顺序与批准页序相同。HTML 模式首尾硬页；Canvas 图片模式不伪造硬页能力。
- 鼠标/触摸翻角、按钮和左右键可翻页，目录能到目标页。
- 页面内容完整，无缺页、拉伸、溢出、裁切或占位内容；图片模式按批准图片逐页像素级复用。
- 若翻页引擎加载失败，页面仍按顺序显示，而不是空白。

## 常见错误

- 为追求“单文件”重新发明翻页动画。
- 把左右跨页截图当成一个物理页。
- 用 iframe 隔离每页，导致本地路径、键盘和文字选择不稳定。
- 在展示阶段改变字号、版心、页码位置或原文。
- 使用 CDN，使作品断网失效。
- 把低分辨率 Canvas 当成源图问题，反复放大 PNG；应先修正 Canvas backing store 的像素比。
- 同时加载多个完整阅读器做对比，造成资源竞争和翻页卡顿；对比页一次只挂载一个阅读器。
