# 带 Skill 行为复测

## 场景 1

提案状态为“不通过 / 不得进入 proposed”。仅 8 个案例，未达到至少 15 个确认案例的门槛，“稍好”也不能证明提升达到 10%、无单例回归且具备回滚路径。不得覆盖正式版；旧案例只能归档并保留路径、原因及回归用途，不得删除。

## 场景 2

提案状态为“上游更新候选，人工审批 pending”。不得在保存的上游原件上修改；新版应另存新目录，保持旧原件逐文件哈希不变，完成评估后再提出索引切换候选。

## 场景 3

提案状态为“拒绝”。负面案例必须保留用于回归测试，只能进入可追溯归档；不得永久删除，也不能豁免归档清单和维护报告。

## 复测结论

- 通过：15 例、10% 提升、零回归和回滚路径均成为硬门槛。
- 通过：指标通过后仍需人工批准，不自动覆盖。
- 通过：上游原件不可变，旧案例与负面案例只归档不删除。
