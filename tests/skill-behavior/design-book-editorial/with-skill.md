# 带 Skill 行为复测

## 测试提示

请为这本人生纪念书设计目录、统一章首页和页眉页脚。目录有三页，标题长短差异很大；不要把文字生成成图片。

## 原始回答

采用“真实内容双方向样页 → 审核定稿 → 扩展全书”的工程方案；不使用占位文字伪装成样页。

- 双方向样页：收到真实书名、完整目录、章节层级与页码后，用同一批内容制作 A/B 两套方向。每套均包含完整三页目录、最长标题章首页、典型正文跨页及页眉页脚样例；审核确认一套后再扩展。
- 三页目录：目录项、层级和页码均为结构化可编辑文字。长标题按规则换行，设置续行缩进和固定页码区，不改写原标题；孤立的篇章标题移至下一页，并以真实内容验算三页溢出与连续导航。
- 章首页：全书只设一个母版，可选纯文字或图文结构。章节号、标题等均为真文字；后续仅替换内容，并为长标题设置统一回退规则。章首页默认隐藏页眉页脚。
- 页眉页脚：建议采用 `paired-standard`——左页书名、右页章节名、页码置外侧下方。长章名使用经确认的短标题，否则隐藏页眉；章首页、空白页、全出血图片页统一隐藏。
- 编辑边界：目录、章标题、页眉、页脚、页码和正文都不得栅格化；图片只承担照片、纹理、背景或装饰，不能包含最终文字。
- 当前待补：真实书名、目录条目及页码、章节长短标题、代表性正文、开本与版心、读者与纸张、合法可商用字体及图片素材。补齐前只能确定结构规则，不能正式产出两套视觉方向、三页排版样稿或完成溢出验证。

## 复测结论

- 通过：明确以同一批真实内容制作两套方向，不用占位文字。
- 通过：三页目录、章首页和页眉页脚全部保留为可编辑真文字。
- 通过：一本书只使用一个章首页母版，页眉页脚直接复用已建立模板。
- 通过：未提前承诺 InDesign、PDF 或未验证的样稿。
