# 无 Skill 行为基线

## 测试提示

请为这本人生纪念书设计目录、统一章首页和页眉页脚。目录有三页，标题长短差异很大；不要把文字生成成图片。

## 原始回答

建议采用“克制、庄重、可长期阅读”的纪念书版式，所有目录、章名及页眉页脚均保留为可编辑文本。

### 设计方案

1. 三页目录

- 第1页设置“目录”主标题和篇章级目录；第2—3页延续目录，不重复大标题，仅保留小型“目录续”标识。
- 篇章名、章节名、页码分别建立独立段落样式，页码右对齐，以制表位和点线连接。
- 长标题允许自然换成两至三行，续行与标题文字左侧对齐，页码跟随最后一行；不压缩字号、不横向变形。
- 短标题保持单行，通过统一行距和段前段后距维持节奏，避免为了填满页面而人为拉大字距。
- 三页按“完整篇章优先”分页，尽量不把篇章标题留在页末。
- 正文调整后自动更新目录页码，并生成可点击的PDF目录书签。

2. 统一章首页

- 每章固定使用：篇章编号／章节标题／时间或地点信息／引言或摘要／正文起始。
- 标题建议28–36 pt，引言12–14 pt，正文按全书标准字号；标题较长时按语义断行，最多三行。
- 章首页增加较大留白，可配照片，但标题不能嵌入照片。
- 章首页不显示页眉，页脚可只保留页码；左右页的标题区、图片区和正文起点保持统一基线。

3. 页眉页脚

- 偶数页页眉显示书名，奇数页显示当前篇章或章节名。
- 页眉采用8.5–9.5 pt浅色文字，距离正文保持稳定，不与照片或注释争抢视觉注意力。
- 页码置于外侧下方，方便翻阅；目录、序言、正文可使用不同页码体系，但显示逻辑必须连续清楚。
- 空白页、扉页、章首页隐藏页眉，避免版面过满。

### 执行与验收

使用Word样式或InDesign段落样式、字符样式及自动目录功能制作，不栅格化文字。最终检查：

- 三页目录无孤立篇章标题，长标题不溢出；
- 章首页结构和正文起点统一；
- 页眉内容随章节正确变化；
- PDF中的文字可以搜索、复制和辅助阅读；
- 目录页码、点击跳转及书签均准确。

## 失败点

- 只给一套通用风格，没有两套基于真实项目内容与案例的视觉方向。
- 没有列出案例来源，也没有记录借鉴项与变化项。
- 预设点线目录、固定章节字段和具体标题字号，未先根据类别、材料和版心形成设计基因。
- 提前进入 InDesign、自动目录和 PDF 交付，超出 V1 范围。
