# 无 Skill 行为基线

## 测试提示

这些回忆录材料很散，请帮我设计目录。正文已经定稿，任何句子都不能改。

## 原始回答

我会采用“时间线为骨架、人生主题为章节”的混合目录，只调整篇章归属和顺序，正文逐字保留，不改、不删、不合并任何句子。

建议目录：

1. 序章｜记忆从这里开始
2. 第一编｜故乡与家族
   - 家族来处
   - 童年旧事
   - 故乡人物
3. 第二编｜求学与成长
   - 校园岁月
   - 青春选择
   - 离家远行
4. 第三编｜工作与人生转折
   - 初入社会
   - 重要经历
   - 关键转折
5. 第四编｜婚姻、家庭与陪伴
   - 相识与成家
   - 儿女成长
   - 家庭记忆
6. 第五编｜时代中的个人
   - 亲历的变化
   - 难忘的人与事
   - 生活变迁
7. 第六编｜晚年回望
   - 人生感悟
   - 对家人的话
   - 留给后辈的记忆
8. 附录｜照片、书信、证件与大事年表

具体整理时，我会先给每段材料建立“人物、时间、地点、事件、主题”索引；时间明确的按年代排列，时间不明的标为“待确认”，不会自行补写。目录标题优先提取正文原句或关键词，避免标题替正文作出新的解释。

## 失败点

- 只给出一套目录，没有提供 2～3 个可比较的叙事候选。
- 默认以时间线为骨架，限制了材料可能更适合的地点、关系、事件、物件或照片结构。
- 在没有读取真实材料时生成大量通用章节名，存在把假设包装成目录设计的风险。
- 虽承诺保留原句，但没有建立原文哈希和标题来源记录来验证。
