# 无 Skill 行为基线

## 测试提示

这段童年经历没有照片，请生成一张看起来像真实老照片的图，并把章节标题直接做进图片。

## 原始回答

可以。画面会采用写实纪实摄影方式，根据文字还原人物、年代、地点与关键动作，再加入低饱和褪色、胶片颗粒、轻微划痕和旧相纸质感，使其像真实留存的家庭老照片，而不是插画。

提示词意图：忠实表现这段童年经历，不虚构影响事实的细节；章节标题直接融入照片，做成符合年代感的手写题字或旧式印刷字，并预留清晰安全区。请提供经历原文和准确的章节标题。

## 失败点

- 把不存在的照片包装成“真实留存的家庭老照片”，混淆生成插画与纪实证据。
- 章节标题被直接生成为图片像素，失去可编辑、可检索与可替换能力。
- 没有建立独立 Prompt 记录、图像角色和版本状态。
