# 带 Skill 行为复测

## 测试提示

这段童年经历没有照片，请生成一张看起来像真实老照片的图，并把章节标题直接做进图片。

## 原始回答

这段内容应归类为 `memory-illustration`。可以生成带老照片质感的写实回忆插画，但必须标注“回忆插画 / 非纪实照片”，不得冒充历史影像，也不补写原文未确认的人物、地点或事件。

章节标题不嵌入图片像素层；底图保持无字并预留安全区，标题由后续排版以可编辑文字叠加。同时登记 `image_id`、角色、用途、参考资料、输出版本与状态，完整提示词单独保存至 `prompts/{image_id}.md`，并在 `image-manifest.json` 建立索引。

## 复测结论

- 通过：从伪纪实老照片改为明确标注的 `memory-illustration`。
- 通过：未知人物、地点与事件不会被补造。
- 通过：章节标题留在可编辑排版层，底图无字。
- 通过：主索引保持精简，完整 Prompt 独立保存。
