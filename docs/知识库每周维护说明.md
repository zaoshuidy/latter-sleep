# 知识库每周维护说明

## 背景与目标

知识库允许认可图片、正式案例、负面案例和重复纠正持续积累，但不能通过永久删除或自动覆盖换取“干净”。每周维护的目标是保持索引有效、证据可追溯、升级可回滚。

## 输入

维护输入为 JSON 数组，每项至少有 `id/kind/state/path`。常用状态：`accepted`、`expired`、`negative`、`duplicate`、`invalid-index`、`updated`、`evolution-candidate`。

正式输入放在 `knowledge/maintenance/inbox/YYYY-MM-DD.json`，输出放在 `knowledge/maintenance/reports/YYYY-MM-DD/`。2026-08-10 已建立首个空基线，表示本周没有新增、归档或升级候选，不代表缺少知识库内容。

## 执行流程

```bash
python skills/evolve-book-skills/scripts/weekly_maintenance.py \
  knowledge/maintenance/inbox/YYYY-MM-DD.json \
  knowledge/maintenance/reports/YYYY-MM-DD
```

输出：

- `weekly-report.md`：新增、归档、失效索引、上游更新候选、进化候选。
- `archive-moves.json`：建议的原路径、归档路径与原因。

认可图片可自动加入索引；过期、重复与负面案例只进入归档计划。脚本不产生永久删除动作。

## 上游更新

`knowledge/upstream/` 下的快照禁止直接编辑或移动。上游发布新版本时：

1. 抓取新 commit 到新版本目录。
2. 保存完整文件清单、许可与逐文件 SHA-256。
3. 作为索引切换候选进入周报。
4. 经人工确认后再更新索引；旧快照继续保留。

## Skill 进化

候选版与正式版使用完全相同的确认案例。少于 15 例、相对提升低于 10%、任一单例回归或缺少回滚路径时直接拒绝。全部满足时仅生成 `proposed`；负责人正式批准后才能进入受控发布。

```bash
python skills/evolve-book-skills/scripts/evaluate_candidate.py baseline.json candidate.json evolution-proposal.json
```

## 人工确认点

- 归档移动清单是否准确。
- 新上游快照是否完整且许可可用。
- 进化案例是否真实、同组且评分依据一致。
- 回滚路径是否指向未覆盖的旧正式版。
- 是否正式批准候选版本。

## 验收标准

- 周报只有五类信息，没有删除项。
- 认可图片已登记，负面案例仍可用于回归。
- 上游原件哈希保持不变。
- 未经人工批准，正式 Skill 文件不变。
