# 《失落人间》油画版封面文字层 V004

## 背景

油画版 V002 的背景、人物和主标题结构已经成立。V003 将全部文字统一为暖白色后，丢失了“人”字的语义冲突，也削弱了副标题与作者名之间的层级。

## 目标

仅重做文字层，使主标题、副标题和作者名形成清楚但克制的对比；背景画面、人物、画布肌理与整体色彩保持不变。

## 锁定设计

- 主标题：保持原竖排字形、字号、位置和间距；“失、落、间”为暖白色，“人”为锈红色并保留轻微右移。
- 副标题：文字仍为“在所有归途之外”；改为横排、小号、疏字距的现代宋体，使用深炭灰色，置于浅色路径区域，不遮挡人物。
- 作者名：文字仍为“早睡的猫”；保持竖排，改为小型朱红色印章感字体，与“人”字呼应，但不使用实体印章边框。
- 不增加描边、发光、投影、底色块、新文字或装饰符号。

## 验收标准

1. 三处文字准确无误，没有增字、漏字或错字。
2. “人”字为锈红色且保留错位，其余主标题为暖白色。
3. 副标题与主标题在方向、字号、颜色和字体气质上形成对比。
4. 作者名与“人”字建立红色呼应，同时明显低于主标题层级。
5. 油画背景和孤独人物的构图不发生实质变化。
6. 生成 V004 独立文件，不覆盖 V001–V003。
