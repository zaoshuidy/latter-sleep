# 《失落人间》目录与页眉页脚功能原型设计

日期：2026-08-14  
状态：用户已选择方向 B「归途坐标」，等待书面规格确认  
项目：`BOOK-LOST-HUMAN-WORLD`

## 背景与目标

本轮用于验证目录与页眉页脚功能是否正常，不代表整本小说的最终内容结构。目录加入序章，不加入尾声、后记或其他后置内容；第一章标题来自现有正文，其余章名由本轮为测试拟定。

成功标准：在 145 × 210 mm 页面上形成一组可视目录跨页和一组正文页眉页脚样张，目录文字、页码、书名和章名均保持可编辑；能验证长短标题、1—3 位页码、左右页切换、隐藏规则和正文安全区。

## 选定视觉方向：B「归途坐标」

### 目录跨页

- 采用连续双页目录，页面比例为 145 × 210 mm，左右页合计 290 × 210 mm。
- 暖灰纸色 `#F1EDE4`、正文墨色 `#1C1B19`、暗红强调色 `#7A2428`，与现有封面、章首页和正文样张一致。
- 使用低对比坐标网格和一条纵向暗红轴线组织目录；网格只承担导航，不模拟地图或真实地点。
- 每个目录项拆分为章序节点、章名和独立页码区。页码右对齐，并覆盖一位、两位、三位数字。
- 不使用点状前导符；短标题保持单行，长标题允许自然换行，续行与章名起点对齐，页码区不随标题换行移动。
- 左页放序章至第四章，右页放第五章至第八章；不得把篇章标题孤立在页尾。

### 页眉页脚

- 正文采用 `paired-standard`：偶数页左上显示书名“失落人间”，奇数页右上显示当前章名。
- 目录跨页左上显示“失落人间”，右上显示“目录”，用于测试左右来源切换。
- 页眉使用小号、低对比、横排真文字；不得侵入正文有效版心。
- 页码使用 `folio-outer` 位置逻辑，左右页镜像位于外侧底部，基线距成品页底 12 mm，不得置于装订侧。
- 章首页、空白页和全出血图片页隐藏页眉与可见页码，但内部计数保持连续。
- 长章名优先使用已确认短标题；本测试没有短标题字段，因此超出安全宽度时隐藏页眉，不截断、不改写章名。

## 产物

1. 一个可交互 HTML 目录跨页原型，使用上述九个测试目录项。
2. 一组正文页眉页脚测试跨页，复用第一章现有可编辑正文片段。
3. 一个结构化 JSON，记录目录项、测试页码、页面规格、颜色、坐标区域、页眉来源和隐藏规则。
4. PNG 预览，用于人工视觉确认；HTML 和 JSON 为可编辑事实源。

本轮不生成 InDesign、PDF、版权页，也不修改第一章正文内容。

## 数据与状态边界

- 目录组件知识库当前仍为 `planned`。本轮只验证排版功能和选定视觉语言，不声称已经完成正式目录组件 reference selection。
- 全书真实章节确定后，应替换测试拟题、重新计算真实页码并完成目录组件知识库门禁，再决定是否进入正式全书目录。
- 页眉页脚直接复用现有模板结构，不创建新的模板类型。

## 验收标准

- 九个测试目录项顺序、标题和测试页码全部准确，第一章标题与源文件一致。
- 目录在双页安全区内无溢出，章名与页码不碰撞；三位页码仍保持同列对齐。
- 偶数页书名、奇数页章名来源正确；页码左右镜像且位于外侧底部 12 mm。
- 章首页、空白页和全出血图片页隐藏规则可在结构化配置中验证。
- 所有文字均为可搜索、可复制、可编辑的文字层；不将目录或页眉页脚栅格化。
- 不改写、删减或校对现有正文。

## 自检

- 无 `TBD`、`TODO` 或未定义占位内容。
- 测试章名与正式第一章的来源边界明确。
- 页眉页脚选择与 B 方案可视化一致。
- 原型范围与目录知识库的正式门禁未混淆。
