# 《失落人间》流畅翻页 V004 设计说明

## 背景

V003 已把 14 个批准物理页固化为 PNG，但仍通过 StPageFlip 的 HTML 模式翻动：每页同时包含 PNG 与透明文字 DOM。用户反馈翻页动作僵硬。

## 目标与验收

- 保留 V003、页面顺序、批准 PNG、目录和现有 `build-book-flipbook` 流程。
- 新增 V004，不重新设计任何图书页面。
- V004 使用 StPageFlip 2.0.7 原生 `loadFromImages` Canvas 模式。
- 在初始化前解码 14 张 PNG，翻页时间为 620ms，阴影上限为 0.20。
- 搜索/辅助文字保留在画布外的静态索引中，不参与翻页形变。
- 保留上/下一页、目录跳转、键盘、页码、URL hash、全屏及离线回退。
- 新增 V003/V004 单实例切换页，方便人工比较手感。

## 技术决策

继续使用已固定的 MIT `page-flip@2.0.7`，不引入 Turn.js、DearFlip 或 WebGL 新依赖。V004 只改变展示渲染方式；内容生产、PNG 资产和 V003 不变。Canvas 模式无法使用 HTML 模式的 `data-density=hard`，本版本优先验证连续翻页手感，首尾页仍由 `showCover: true` 保持封面展开逻辑。

## 失败处理

图片预解码失败不阻断启动；引擎初始化失败时按顺序显示 14 张 PNG。用户若不认可 V004 手感，可直接继续使用未修改的 V003。

## 批准

用户已于 2026-08-17 批准先制作 Canvas V004 并与 V003 做动态对照。
