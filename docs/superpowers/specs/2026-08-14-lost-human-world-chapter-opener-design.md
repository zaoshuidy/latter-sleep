# 《失落人间》章首页母版设计

## 背景

《失落人间》是 32 开文学小说，第一章为《车窗里的故乡》。当前已经完成 50 条章首页案例库、正式检索和五案例视觉板。用户选择案例 2《捡来的瓷器史》与案例 5《一群马 满天星》作为本轮结构参考。

## 目标用户

- 主要读者：当代中文文学读者。
- 制作者：个人图书项目维护者，需要稳定复用同一章首页母版。

## 问题分析

视觉目标不是复述“返乡、死亡、城市”等具体情节，而是用抽象边界、空缺和单侧文字表现“不被任何地方接纳”的悬置感。当前正式 selection 校验只接受封面字段，无法接受章首页检索结果中的七个组件字段，因此需要一项最小兼容修复。

## 选定方案

### 母版结构

- 使用跨页章首页。
- 左页保留大面积浅色空场，仅出现一条从页边进入、在书沟前中断的暗色不规则边界。
- 右页承载可编辑章号与章题，采用单侧聚焦和错落竖排；文字不进入背景图。
- 暗色形状不画成道路、车窗、人物或故乡建筑，只作为“边界存在但无法闭合”的抽象象征。
- 章首页隐藏页眉页脚；后续章节只替换章号和章题，不重新设计版式。

### 案例字段借用

- `CHO-CN-0006`：借用 `visual_strategy=abstract`、`text_image_relationship=integrated`、`whitespace=high`；重新设计边界形状，不复制瓷片轮廓、原章题、折切结构或具体线条路径。
- `CHO-CN-0011`：借用 `visual_strategy=typography`、`chapter_title_zone=vertical`、`text_image_relationship=text-only`、`whitespace=high`；按本项目章题长度重排，不复制原书断行、手工纸效果或具体字距。

## 技术影响

- AI 流程：正式 selection 的允许字段改为按 `component_type` 从检索权重表读取；封面行为保持不变。
- 编辑设计：新增一份 `status=draft` 的章首页 selection，经 schema 和 Prompt-safety 校验后再请求一次批准。
- 图像：本阶段不调用 imagegen；最终若生成装饰背景，也只生成无字背景。
- 排版：章号、章题保留为可编辑真文字；不执行 InDesign。
- 前端、数据库、权限、部署：无影响。

## 执行流程

1. 最小修复组件字段校验，使章首页使用自身七字段。
2. 写入案例 2＋5 的 draft selection，并通过 schema、Prompt-safety 与 retrieval 证据校验。
3. 用户一次确认 selection ID 与 SHA 后，将状态改为 approved。
4. 输出《第一章 车窗里的故乡》章首页母版规格和可编辑文字层参数。
5. 用户视觉确认后，才决定是否生成无字背景样图。

## 验收标准

- selection 只含 `CHO-CN-0006` 与 `CHO-CN-0011`，且字段均来自本轮检索的正分证据。
- 封面 selection 的既有字段校验不回归。
- 章首页标题与章号不进入背景图。
- 版式表达克制、抽象，不出现人物、道路、车窗、疾病或葬礼的直白叙事图像。
- 同一母版可通过替换章号与章题复用于全书。

## 边界

- 不复制任何案例的具体图形、原文字、照片、色值和独特组合。
- 不推断纸张、模切、烫印或装订工艺。
- 本阶段不生成图片、不执行 InDesign、不扩展目录或正文设计。
