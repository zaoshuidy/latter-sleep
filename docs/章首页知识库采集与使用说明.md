# 章首页知识库采集与使用说明

## 背景

章首页不是普通内页，也不是把章节文字压进一张背景图。它负责建立章节进入节奏，并在同一本书中稳定复用章号、章题、图像和留白关系。

- 有效记录：50
- 本地原图：50

多轮调研由多个 Agent 按年份、出版社、设计工作室和奖项案例分线采集。只收实际图片中能辨认章首页、分辑扉页或采访／篇目起始页，且正式出版年有独立证据的案例。普通正文、目录、封面、只在文字中声称“有章首页”但没有直图的项目全部拒绝。

## 每条记录的七个核心字段

1. `opening_mode`：单页或跨页。
2. `visual_strategy`：排版、摄影、插画、抽象、图像或混合。
3. `chapter_number_zone`：章号所在区域；无章号时明确为 `none`。
4. `chapter_title_zone`：章题所在区域。
5. `image_role`：无图、背景、插画、摄影或装饰。
6. `text_image_relationship`：纯文字、分离、叠加、相邻或整合。
7. `whitespace`：高、中、低。

这些字段只记录当前图片可见结构，不根据书名、设计说明或常识补画面事实。

## 使用门禁

当前已达到 50 条，查询按七个字段加权，稳定返回 5 本不同书，再由人逐图指定可借字段和排除字段。后续维护仍必须保持同样证据标准，不能把封面案例冒充章首页案例。

公开展示或可下载只证明来源可访问，不等于获得商业复制、转载、改编或印刷授权。知识库只借用结构字段；不得复刻原案例的图像、字形、专有工艺组合或完整页面。
